An AI-powered YouTube video chatbot that lets you ask questions about a YouTube video and get answers based on its transcript.

The project uses Retrieval-Augmented Generation (RAG) to retrieve relevant parts of the video transcript before generating an answer with Gemini.

🚀 Features
🎥 Fetches YouTube video transcripts
✂️ Splits transcripts into smaller chunks
🧠 Creates embeddings using Google Gemini
🗄️ Stores embeddings in a FAISS vector database
🔎 Retrieves relevant transcript sections for each question
🤖 Uses Gemini to generate answers
💬 Simple Streamlit interface
🔐 API keys stored securely using .env
